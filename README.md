# vfox-go-crond

> **Deprecated** — this plugin is replaced by [jbox-web/aqua-registry](https://github.com/jbox-web/aqua-registry).

[![CI](https://github.com/jbox-web/vfox-go-crond/workflows/CI/badge.svg)](https://github.com/jbox-web/vfox-go-crond/actions)

A plugin for the [mise version manager](https://github.com/jdx/mise) to install [go-crond](https://github.com/webdevops/go-crond)

## Install

```
mise plugin install go-crond https://github.com/jbox-web/vfox-go-crond.git
```
